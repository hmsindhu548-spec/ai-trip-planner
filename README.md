# Roamly — AI Trip Planner

A full-stack starter built with Next.js App Router, React, TypeScript, Convex, Arcjet, and OpenAI. The UI collects destination, duration, budget, party size, travel style, and interests; the server validates input, applies Arcjet protection, and generates a structured itinerary.

## Requirements
- Node.js 20.9+
- npm
- Convex account
- Arcjet API key
- OpenAI API key

## Run locally
1. Unzip the project and open its folder in a terminal.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Copy `.env.example` to `.env.local` and fill in the keys.
4. Start Convex in one terminal:
   ```bash
   npx convex dev
   ```
   Sign in when prompted and create a Convex project. This generates `convex/_generated` and your `NEXT_PUBLIC_CONVEX_URL`. Put the URL into `.env.local`.
5. Start Next.js in another terminal:
   ```bash
   npm run dev
   ```
6. Open http://localhost:3000.

## Environment variables
- `NEXT_PUBLIC_CONVEX_URL`: generated by `npx convex dev`.
- `ARCJET_KEY`: create a site/key in the Arcjet dashboard.
- `OPENAI_API_KEY`: API key for itinerary generation; keep it server-side.
- `OPENAI_MODEL`: optional; defaults to `gpt-4o-mini`.

## Deploy
### Convex
Run `npx convex deploy` and use the production deployment URL in your production environment variables.

### Vercel
1. Push this project to a GitHub repository.
2. Import the repository in Vercel.
3. Add `NEXT_PUBLIC_CONVEX_URL`, `ARCJET_KEY`, `OPENAI_API_KEY`, and optionally `OPENAI_MODEL` in Vercel Project Settings → Environment Variables.
4. Deploy. Keep secrets out of Git and never prefix secret keys with `NEXT_PUBLIC_`.

## Important implementation notes
- Arcjet protects the generation endpoint with Shield, bot detection, and a fixed-window rate limit. Tune the rules for your traffic and cost limits.
- The Convex schema and `trips.save` / `trips.recent` functions are included. The initial UI does not yet save generated trips; wire the mutation into the client flow when you want persisted trip history and add authentication/ownership before storing private itineraries.
- This starter does not include authentication, booking APIs, live flight/hotel prices, or live map/places data. AI-generated estimates and opening-hour suggestions must be verified with providers before travel.
- If a key is missing, the API route returns a clear configuration error instead of silently pretending the AI ran.
